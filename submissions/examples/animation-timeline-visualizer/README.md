# Animation Timeline Visualizer

An interactive demo that visualizes the duration, delay, and playback of EaseMotion CSS animations.

## Features
- Select any EaseMotion animation class.
- See a timeline with delay and active duration markers.
- Play, pause, restart, and adjust speed.
- Real‑time preview and generated HTML snippet.

## How to run
Open `demo.html` in a browser. No build steps are required – everything is self‑contained.

## Files
- `demo.html` – the demo page loading the visualizer.
- `style.css` – custom styling for the visualizer (glassmorphism, dark mode support).
- `README.md` – this documentation.
